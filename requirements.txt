# Runtime dependencies for the Vercel Python Function (api/index.py).

# Deliberately NOT generated from pyproject.toml. That file keeps the FastAPI
# layer in an optional `api` extra so the core library stays dependency-light,
# and Vercel installs a project's main dependencies only -- following it would
# deploy a function with no web framework in it.
#
# Two things in the extra are absent on purpose:
#   uvicorn        Vercel supplies the ASGI server; shipping a second one just
#                  spends bundle budget we are already short of.
#   sse-starlette  never imported -- /api/events is a plain StreamingResponse,
#                  and the deployed frontend does not open a stream at all.
#
# Pinned, because the bundle has to fit in 250 MB uncompressed and a minor
# release of numpy or ortools is free to change that by tens of megabytes.
